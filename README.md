# Obid Bachelor Thesis

This repository contains the implementation, evaluation,
evidence, and report-support material for Obid's bachelor thesis.

The project continues from the completed Yacoub thesis handoff.

Yacoub provides the compatible workflow-to-action infrastructure
and integration boundary.

Obid investigates and implements the agentic decision and
reliability layer, including agent behavior, bounded memory,
runtime validation, action policy, HITL, and repeated evaluation.

## Current status

Pre-Step-1 repository bootstrap.

The formal scope, collaboration boundary, research questions,
repository structure, and active planning documents will be
created during Steps 1 and 2.

## Reference material

`reference/` contains read-only historical and collaborator
material. It is not the active implementation area for Obid.
